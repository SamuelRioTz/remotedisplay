# Security policy

Remote Display gives remote control of a computer, so please handle vulnerabilities
privately.

## Reporting a vulnerability

Email **info@remotedisplay.app** with a description of the problem, the affected
version (client and host), and steps to reproduce. Please do not open a public GitHub
issue for security problems. You should get an acknowledgement within a few days; the
fix ships in the next release and the report is credited in the release notes unless
you prefer otherwise.

## Scope

The clients (Windows, macOS, iOS/iPadOS, Android) and the macOS host in this
repository. Issues in the upstream RustDesk engine should be reported to
[RustDesk's security policy](https://github.com/rustdesk/rustdesk/blob/master/docs/SECURITY.md)
as well; we track upstream releases and re-apply our changes on top of them.

## Supported versions

Only the latest release is supported.
